Данный репозиторий содержит комплекс выполненных лабораторных работ по изучению синтаксиса, концепций объектно-ориентированного программирования (ООП), структур данных, встроенных механизмов и продвинутых возможностей языка Java.

## Структура репозитория

### 📂 [Лабораторная работа №1](lab1) — Базовый синтаксис
* Вводные программы для знакомства с компиляцией и запуском через CLI.
* Решения задач на циклы, условия и простые алгоритмы обработки строк.
* **Ключевые файлы:** `JavaHelloWorldProgram.java`, `Primes.java`, `Palindrome.java`.

### 📂 [Лабораторная работа №2](Lab2) — Объектно-ориентированное программирование
* Проектирование иерархии классов на примере предметной области «Мебель».
* Реализация абстрактных классов, инкапсуляции, наследования и полиморфизма.
* **Ключевые файлы:** `Furniture.java` (base), `Table.java`, `Chair.java`, `Bed.java`, `Main.java`.

### 📂 [Лабораторная работа №3](Lab3) — Структуры данных
* Разработка собственной параметризованной хэш-таблицы с разрешением коллизий методом цепочек.
* Применение структуры в мини-системе учета персонала.
* **Ключевые файлы:** `HashTable.java`, `EmployeeManagement.java`.

### 📂 [Лабораторная работа №4](Lab4) — Исключения и Ввод-Вывод
* Обработка стандартных и кастомных исключений (`try-catch`, `try-with-resources`).
* Реализация побайтового копирования файлов и ведение логов ошибок в текстовый файл.
* **Ключевые файлы:** `ArrayAverage.java`, `FileCopier.java`, `MathCalculator.txt`.

### 📂 [Лабораторная работа №5](Lab5) — Регулярные выражения
* Использование классов `Pattern` и `Matcher` для валидации, поиска и модификации текстов.
* Проверка безопасности паролей, валидация IPv4-адресов, парсинг чисел и замена строк.
* **Ключевые файлы:** `IPAddress.java`, `PasswordChecker.java`, `NumberFinder.java`.

### 📂 [Лабораторная работа №6](Lab6) — Коллекции и многопоточные контейнеры
* Создание кастомного обобщенного `Stack<T>`. Работа с Java Collections Framework.
* Частотный анализ текста (Топ-10 слов) и создание потокобезопасного трекера продаж на `ConcurrentHashMap`.
* **Ключевые файлы:** `Stack.java`, `TopWords.java`, `SalesTracker.java`.

### 📂 [Лабораторная работа №7](Lab7) — Многопоточное программирование
* Параллельная обработка массивов и матриц с распределением данных между потоками.
* Использование пулов потоков (`ExecutorService`, `Callable`, `Future`) и синхронизаторов (`CountDownLatch`).
* **Ключевые файлы:** `ArraySumTask.java`, `MatrixMaxFinder.java`, `WarehouseApp.java`.


### 📂 [Лабораторная работа №8](Lab8) — Создание приложения
* Пользовательская аннотация `@DataProcessor` для маркировки методов и динамический вызов методов через рефлексию (Reflection API)
* Реализация параллельной обработки данных с использованием `parallelStream()` и асинхронное выполнение через `ExecutorService` и `Future`
* **Ключевые файлы:** `Main`.
