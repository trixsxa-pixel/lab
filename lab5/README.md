# Лабораторная работа №5: Регулярные выражения в Java

Репозиторий содержит решения задач, демонстрирующих применение регулярных выражений (`Regular Expressions`) с использованием классов `Pattern` и `Matcher` для поиска, валидации и модификации текстовых данных.

## Содержимое
* `NumberFinder.java` — поиск и вывод всех чисел (включая целые и вещественные с плавающей точкой) в заданном тексте.
* `WordFinder.java` — поиск всех слов в тексте, начинающихся на определенную букву (регистронезависимо).
* `CaseSwapper.java` — изменение разметки текста: находит места, где маленькая буква граничит с большой (`[a-z][A-Z]`), и выделяет их восклицательными знаками (`!$1!`).
* `IPAddress.java` — валидация IPv4-адреса с проверкой корректности диапазонов каждого октета (от 0 до 255).
* `PasswordChecker.java` — проверка пароля на безопасность: длина от 8 до 16 символов, обязательное наличие хотя бы одной цифры и одной заглавной буквы.

## Запуск

Для сборки и запуска любого из модулей скомпилируйте файлы через терминал:

```bash
# Пример 1: Поиск чисел
javac NumberFinder.java && java NumberFinder

# Пример 2: Проверка IP-адреса
javac IPAddress.java && java IPAddress

# Пример 3: Проверка пароля
javac PasswordChecker.java && java PasswordChecker
