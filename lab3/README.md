# Лабораторная работа №3: Структуры данных и Хэш-таблицы в Java

Репозиторий содержит реализацию собственной хэш-таблицы для работы с парами "ключ-значение", а также пример её практического применения для управления данными.

## Содержимое
* `HashTable.java` — параметризованный класс хэш-таблицы (`HashTable<K, V>`). Реализует разрешение коллизий методом цепочек (используя встроенный `LinkedList`), вычисление хэша, а также базовые операции: добавление (`put`), получение (`get`) и удаление (`remove`).
* `EmployeeManagement.java` — демонстрационный класс системы учета сотрудников. Использует структуру данных для хранения, быстрого поиска по ID и вывода информации о персонале.

## Запуск

Для сборки и запуска проекта скомпилируйте файлы и запустите исполняемый класс:

```bash
# Компиляция файлов проекта
javac HashTable.java EmployeeManagement.java

# Запуск программы учета сотрудников
java EmployeeManagement
