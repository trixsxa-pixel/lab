# Приложение для обработки данных

Java-приложение, демонстрирующее обработку данных с использованием аннотаций, параллельных потоков и многопоточности.

## Возможности

- Пользовательская аннотация `@DataProcessor` для маркировки методов
- Динамический вызов методов через рефлексию (Reflection API)
- Параллельная обработка данных с использованием `parallelStream()`
- Асинхронное выполнение через `ExecutorService` и `Future`
- Чтение и запись файлов

## Требования

- Java 8 или выше

## Структура проекта
.
├── Main.java # Точка входа и основная логика приложения
├── input.txt # Автоматически создаваемый входной файл
└── output.txt # Автоматически создаваемый выходной файл
## Описание классов

| Класс | Назначение |
|-------|------------|
| `@DataProcessor` | Аннотация времени выполнения для маркировки методов обработки данных |
| `FilterProcessor` | Фильтрует слова короче 4 символов |
| `TransformProcessor` | Преобразует строки в верхний регистр с логированием имени потока |
| `DataManager` | Управляет загрузкой, обработкой и сохранением данных |
| `Main` | Демонстрирует полный рабочий процесс |
