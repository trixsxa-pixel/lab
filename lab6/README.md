# Лабораторная работа №6: Коллекции и многопоточные контейнеры в Java

Репозиторий содержит решения задач, демонстрирующих работу со стандартными коллекциями Java Framework, создание кастомных обобщенных структур данных и применение потокобезопасных контейнеров для параллельной обработки.

## Содержимое
* `Stack.java` — собственная реализация структуры данных «Стек» (LIFO) на базе массива с использованием обобщений (`Generics`). Поддерживает операции `push`, `pop` и `peek`.
* `TopWords.java` — программа для анализа текстового файла. Подсчитывает частоту встречаемости слов с помощью `Map` (ингорируя регистр и знаки препинания) и выводит топ-10 самых частых слов с использованием кастомной сортировки `Comparator`.
* `SalesTracker.java` — потокобезопасная система учета продаж на базе `ConcurrentHashMap`. Позволяет параллельно добавлять проданные товары, рассчитывать общую выручку и находить самую популярную позицию.

## Запуск

Для сборки и запуска любого из модулей воспользуйтесь командами компиляции в терминале:

```bash
# Пример 1: Анализ текста (убедитесь, что файл text.txt существует по указанному пути)
javac TopWords.java && java TopWords

# Пример 2: Демонстрация работы кастомного стека
javac Stack.java && java Stack

# Пример 3: Мониторинг продаж
javac SalesTracker.java && java SalesTracker
