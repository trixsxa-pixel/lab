# Лабораторная работа №2: ООП в Java (Иерархия классов «Мебель»)

Репозиторий содержит решение задачи на применение принципов объектно-ориентированного программирования (ООП) в Java: инкапсуляция, наследование, полиморфизм, использование абстрактных классов, перегрузка методов и статических свойств.

## Структура классов
Проект моделирует структуру производства/учета мебели:
* `Furniture.java` — абстрактный базовый класс с общими свойствами (имя, материал, цена), счетчиком объектов (`static`) и абстрактным методом `assemble()`.
* Наследники 1-го уровня:
  * `Table.java` — класс стола (добавлено поле формы, перегружен метод `displayInfo`).
  * `Chair.java` — класс стула (свойство наличия спинки).
  * `Bed.java` — класс кровати (размер спального места).
* Наследники 2-го уровня (расширенный функционал):
  * `ComputerTable.java` — компьютерный стол (кабель-менеджмент, метод `setupTech`).
  * `OfficeChair.java` — офисное кресло (газлифт).
  * `SofaBed.java` — диван-кровать (метод трансформации `transform`).
* `Main.java` — точка входа, демонстрация полиморфизма и работы со статическими счетчиками.
