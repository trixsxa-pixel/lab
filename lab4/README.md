# Лабораторная работа №4: Обработка исключений и ввод-вывод в Java

Репозиторий содержит решения задач, демонстрирующих механизмы обработки исключений (`Exception Handling`), работу с потоками ввода-вывода (`I/O Streams`) и логирование ошибок в файлы.

## Содержимое
* `ArrayAverage.java` — вычисление среднего арифметического элементов массива строк. Реализует перехват `NumberFormatException` (если элемент не число) и `ArrayIndexOutOfBoundsException` (выход за границы), позволяя программе корректно завершить расчет.
* `FileCopier.java` — побайтовое копирование файлов с использованием `FileInputStream` и `FileOutputStream`. Применяет конструкцию *try-with-resources* для автоматического закрытия потоков и перехватывает `IOException`.
* `MathCalculator.java` — математический калькулятор с поддержкой кастомного исключения `CustomUnsupportedOperationException`. При делении на ноль или вводе неверной операции генерирует ошибку и записывает стек-трейс в текстовый лог `math_errors.txt`.

## Запуск

Для сборки и запуска любого из модулей скомпилируйте файлы через терминал:

```bash
# Пример 1: Калькулятор и логирование ошибок
javac MathCalculator.java && java MathCalculator

# Пример 2: Копирование файлов (перед запуском создайте source.txt)
javac FileCopier.java && java FileCopier

# Пример 3: Обработка массива
javac ArrayAverage.java && java ArrayAverage
