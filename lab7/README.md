# Лабораторная работа №7: Многопоточное программирование в Java

Репозиторий содержит решения задач, демонстрирующих основы многопоточности (`Multithreading`) и использование современных инструментов синхронизации из пакета `java.util.concurrent` для параллельной обработки данных.

## Содержимое
* `ArraySumTask.java` — параллельное вычисление суммы элементов массива. Массив делится на равные части между 4 потоками, обработка запускается через `ExecutorService`, а результаты собираются с помощью `Future`.
* `MatrixMaxFinder.java` — многопоточный поиск максимального элемента в матрице. Каждый поток изолированно обрабатывает свою строку матрицы, после чего главный поток определяет глобальный максимум.
* `WarehouseApp.java` — имитация работы склада (погрузка и разгрузка товара весом 150 кг). Синхронизация потоков-грузчиков (`Worker`) реализована с помощью утилиты `CountDownLatch` для фиксации завершения этапов работы.

## Запуск

Для сборки и запуска любого из модулей скомпилируйте файлы через терминал:

```bash
# Пример 1: Многопоточная сумма массива
javac ArraySumTask.java && java ArraySumTask

# Пример 2: Поиск максимума в матрице
javac MatrixMaxFinder.java && java MatrixMaxFinder

# Пример 3: Модель склада (работа с CountDownLatch)
javac WarehouseApp.java && java WarehouseApp
